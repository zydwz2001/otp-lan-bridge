# Chrome 插件使用方法

## 安装

1. 下载并解压 `verification-code-transfer-chrome.zip`。
2. 打开 `chrome://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择含有 `manifest.json` 的解压目录。
4. 打开任意普通网页，在右侧浮窗点击“展开设置”。

不要直接选择 ZIP，也不要只选择外层同名文件夹。如果 Chrome 提示缺少清单文件，请继续进入下一层目录。

## 配对

插件自动优先使用授权后的 USB。使用 USB 时按 [数据线连接使用方法](USB_CONNECTION.md) 完成一次设备授权；地址、端口可留空，配对码仍需填写。下面的地址要求适用于 Wi-Fi。

2.3.3 在设置底部增加一行“无 Wi-Fi？用数据线，需 USB 调试”，点击可展开操作步骤和手机设置路径。也可以在 App 最下方点击“开启 USB 调试”，按提示跳转到系统设置。

1. 先在手机 App 完成“通知读取设置”和“防止后台断开”，再点“配对电脑”，保持 App 页面在前台。
2. “手机 Wi-Fi 地址”默认留空，请按 App 当前显示的内容输入。
3. 端口不会预填，请照 App 当前显示的端口输入（当前版本通常显示 `42871`）。
4. 输入 App 显示的 6 位配对码，点击“配对手机”。
5. 点击新打开窗口中的“连接手机”。Chrome 询问“访问本地网络中的其他设备”时选择“允许”。如果以前已允许过，不会重复出现权限弹窗，会直接继续连接。
6. 配对成功后，在手机 App 选择短信应用并点“开始传递”。

独立的白色连接窗口负责请求 Chrome 设备或本地网络权限，避免 HTTPS 网页把手机的 `ws://` 地址当成混合内容拦截。点击原有“连接手机”时，Chrome 可能先显示 USB 设备选择；不用数据线时取消选择即可继续 Wi-Fi。配对成功后，后台扩展会自动维持连接。

## 手机地址自动恢复

路由器可能在几天后为手机分配新的 Wi-Fi 地址。旧地址连接失败时，插件会同时尝试已配对手机发布的稳定局域网名称，并搜索原地址所在的 Wi-Fi 网段。只有能通过原配对密钥验证的手机才会被接受；认证后，App 会在加密状态消息中返回当前真实 Wi-Fi 地址，插件自动保存并刷新浮窗。

从 2.2.5 开始，只要手机与电脑仍在同一个可互访的 Wi-Fi，即使从 `192.168.18.x` 换到 `192.168.1.x` 之类的不同网段，也不需要手动改地址或重新配对。手机 App 和 Chrome 插件都需更新到 2.2.5 或更高版本；部分访客网络会屏蔽局域网名称解析，此时仍可在浮窗中手动填写 App 当前显示的地址并保存。
地址已经保存但仍显示离线时，可在同一区域点击“重新连接”；无需解除配对。

关闭并重新打开 Chrome 后，插件会先检查已授权的 USB 手机，再尝试保存的 Wi-Fi 地址，并用 Chrome 持久化闹钟兜底唤醒断线重试；打开网页、切换标签或重新聚焦浏览器时也会主动补连。VPN 不参与手机连接。

## 配置手机号

- “常用手机号”用于网页面板的手动填写，完整号码只保存在扩展本地存储。
- 不希望面板出现在当前网站时，可点击浮窗底部的“隐藏本站”。

## 在网页上使用

1. 点击网页手机号输入框。
2. 点击悬浮面板“点击手机号输入框，一键填充并等待”。这会写入手机号，并开启 5 分钟等待窗口。
3. 自己点击网站的“发送验证码”。
4. 验证码到达后，点击“写入验证码并登录”，无需提前点击验证码输入框。
5. 插件只会在同一表单中能明确识别登录/提交按钮时自动点击；识别不明确时只填写验证码，由你确认后提交。

验证码与本次 5 分钟等待共用一个倒计时，填写后仍会保留。验证码页面可点“返回填充”，需要再次填写时点“查看验证码”返回验证码页面。

悬浮面板默认更靠近页面右上角并缩小尺寸；点击输入框时如果发生遮挡，还会自动避让。手工拖动后，之后新打开的网页会沿用最后位置；面板也可以折叠或对当前网站隐藏。

## 更新与卸载

- 源码目录更新后，在 `chrome://extensions` 点击扩展卡片的刷新按钮，然后刷新已经打开的网页，让页面加载新脚本。
- Chrome 2.3.1 会在旧页面脚本失效时清除旧在线状态，提示“插件已更新或重载，请刷新当前网页后继续”。看到该提示时刷新网页即可，原配对保留。
- 如果换了扩展安装目录，Chrome 可能把它识别为另一份扩展，需要重新配对。
- 建议覆盖原来的扩展目录后刷新，保留原配对及 USB 授权；改成新的扩展身份时，设备授权也需重新完成。
- 卸载扩展会删除浏览器端的手机号、配对材料和面板设置，不影响手机 App。
