# USB 直连模式

USB 模式不经过 Wi-Fi、路由器或 TUN，适用于无线网络开启设备隔离的情况。TUN 可以保持开启。

## 首次准备

1. 在手机“设置 → 我的设备/全部参数”中连续点击系统版本，开启开发者选项。
2. 在“更多设置 → 开发者选项”中开启“USB 调试”。
3. 用支持数据传输的 USB 线连接电脑，并在手机弹窗中允许这台电脑调试。
4. 安装 1.0.3 或更高版本的 Android App，并保持桥接服务启用。

## 建立转发

在项目目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\start-usb-bridge.ps1
```

脚本显示成功后，在 Chrome 扩展中填写：

- 手机 IP / USB 地址：`127.0.0.1`
- 端口：`41837`
- 配对码：手机当前显示的 6 位码

USB 线拔出或电脑重启后，需要再次运行脚本；已完成的设备配对不会失效。
