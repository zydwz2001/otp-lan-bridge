# Android App 使用方法

## 安装说明

App 的应用 ID 是 `io.github.zydwz2001.wifiotprelay`。安装后需要为“验证码传递”单独开启通知使用权，并重新完成浏览器配对。

## 通知读取状态

- 前台必须显示“通知读取：已连接，可以接收短信”，真实短信验证码才能自动传递。
- 如果权限开关已经开启，但页面显示“通知读取未连接”，顶部会出现修复卡。点击“立即修复通知读取”，在系统页面先关闭再重新开启“验证码传递 · 通知读取”，返回 App 后等待几秒。
- “发送测试验证码”只测试手机和浏览器之间的连接，不能证明系统通知读取已经连接。

## 首次设置

1. 打开“验证码传递”。
2. 按首次引导进入系统设置，允许“验证码传递 · 通知读取”。未开启前 App 不会开始传递。
3. 返回 App，在状态卡里选择正在使用的短信应用。
4. 点击“开始传递”。
5. 把状态卡中分开显示的 Wi-Fi 地址、端口和配对码填入 Chrome 插件。
6. 浏览器询问“访问本地网络中的其他设备”时选择“允许”。

## 后台运行

开始传递后，Android 会自动显示一个低优先级常驻通知，用于维持手机与浏览器的连接。App 不再提供含义不清的“后台运行设置”按钮；通常不需要额外配置。

本版本不会在开机时自行启动；手机重启后请打开 App 并点击“开始传递”。

## 测试

浏览器进入等待状态后，点击 App 的“发送测试验证码（可选）”。若浏览器能收到测试码，说明 Wi‑Fi、配对、加密协议和网页面板链路正常；真实短信仍失败时，应重点检查短信 App 包名和锁屏通知内容。
